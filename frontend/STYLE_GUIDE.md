# CampusClaw 前端视觉规范

## 方向

采用「书卷文雅」方案：米白纸张感、北大红重点操作、温和的细分隔线、充足留白。界面应保持简约，资料内容始终比装饰更醒目。北大红的网页色值 `#94070A` 参考[北京大学视觉形象识别系统](https://vim.pku.edu.cn/docs/20171026163443134569.pdf)。本项目使用自有的 `CC` 字标，不使用北京大学校徽或校名作为产品标识。

## 设计变量

颜色统一在 `src/styles.css` 的 `:root` 中定义；常用间距、圆角和阴影优先复用现有变量。响应式布局的具体尺寸可以按页面需要设置。新增页面不要直接写新的十六进制颜色；需要新颜色时先说明用途并补充变量。

- 品牌色：`--brand`，用于主要按钮、链接、焦点和少量强调。
- 背景与表面：`--canvas`、`--paper`，构成米白底与内容卡片。
- 文字：`--ink`、`--muted`；边界：`--line`。
- 状态色：`--danger`、`--success`，只表达状态，不借用品牌色。
- 间距：以 `--space-*` 阶梯为主；圆角使用 `--radius-*`。

## 页面与组件

- 标题可使用宋体或本机衬线字体回退；正文和表单使用清晰的无衬线字体。不依赖远程字体。
- 主要操作每个区域最多一个；次要操作使用描边或文字按钮。
- 新表单复用 `.field`、`.button`、`.button-secondary`；内容容器复用 `.card`；错误与成功消息复用 `.error`、`.notice`。
- 教师和学生界面保持同一布局语言。角色差异只体现为可用操作，不另起一套配色。
- 移动宽度下改为单栏，保证文字、按钮和表单不产生横向滚动。
- 保留语义标签、可见的键盘焦点、明确的表单标签；状态提示应可被辅助技术感知。

## 后续改动的检查

新增或修改页面时，先检查是否可复用现有变量与组件样式，再在桌面和约 390px 宽的手机视口检查布局。提交前运行 `npm run typecheck` 和 `npm run build`。涉及登录、权限或材料展示时，还应运行相应的浏览器验收用例。
