## Why

当前系统已能认证师生、隔离班级并保存原文件及一份完整提取文本，但无法在长材料中检索相关段落，也无法让回答指回确切出处。第四课要求在第 3 课基础上增加限定本班的关键字、向量与混合检索，以及有证据才生成的简短可追溯回答。

## What Changes

- 将已有材料正文切为带序号和字符区间的切片；支持自动窗口、自定义分隔符和 Markdown 标题层级三种策略，教师可对本班材料显式重建索引。
- 提供 `keyword`、`vector`、`hybrid` 三种检索模式，默认混合；结果包含可打开的材料出处、切片位置和来自关系库正文的摘录，无足够依据时返回空命中。
- 在服务端以登录会话中的班级标识约束关键字、向量及回表查询；请求伪造班级不改变范围。
- 在 Compose 内部增加 Qdrant，切片正文保留在 MySQL；服务端调用嵌入与对话网关，浏览器只访问本站 `/api`。
- 增加简短问答：先检索本班前 4 个切片，有命中才调用对话模型，回答中的编号与出处列表一一对应；无命中直接返回固定文案。
- 前端增加检索、出处查看、问答与教师重建索引入口，沿用现有「书卷文雅」视觉规范。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 切片与索引、三种检索模式、班级隔离、出处与简短有据问答。

### Modified Capabilities

- `teaching-materials`: 教师上传可提交切分策略，现有文件安全校验与材料事务行为保持不变。
- `web-experience`: 师生可在现有材料页面使用本班检索和出处；教师可选择切分策略与重建索引。
- `compose-runtime`: 增加仅在内部网络使用的向量库及服务端模型网关配置，同时维持单一浏览器入口和一条启动命令。

## Impact

预计涉及 Go 检索模块、MySQL 迁移与历史材料补索引、Compose/Qdrant、配置、同源 API 和 React 材料页面；沿用现有认证、上传、下载与班级授权。原材料和 `knowledge_entries` 原文继续保留，新增索引失败不回滚已成功的材料上传。规划依据为[第四课课件](https://devops.hello1023.com/%E8%AF%BE%E4%BB%B6/%E7%AC%AC4%E8%AF%BE-%E8%AF%BE%E4%BB%B6-%E5%8F%AF%E8%BF%BD%E6%BA%AF%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A3%80%E7%B4%A2/index.html)。本变更仅编写 OpenSpec 规划产物，不包含实现。
